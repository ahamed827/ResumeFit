# ResumeFit Frontend Application

Next.js 14 App Router, TypeScript, and Tailwind CSS client application for ResumeFit.

## Key Features
- Clean SaaS design with dark-mode palette and indigo accents
- Complete auth flow (login, register, forgot/reset password) with automatic token rotation
- Interactive dashboard with Recharts metric visualizations
- Resume library with instant file uploading, status tracking, and extracted profile editing
- Job library supporting raw pasting and TXT/PDF/DOCX file uploads
- Evaluation wizard and detailed match reports with visual circular score dial, component bars, matched skill evidence cards, and personalized improvement roadmaps
- Kanban-style application tracker with filter and search
- Dedicated platform telemetry dashboard for platform administrators

## Development

```bash
npm install
npm run dev
```
